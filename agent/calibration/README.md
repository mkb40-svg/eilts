# Калибровка экзаменатора

Сюда кладутся работы Writing с оценкой, которую поставил преподаватель с опытом IELTS.
Команда `python -m ielts_agent calibrate` (или workflow «Калибровка экзаменатора») прогоняет их
через ИИ и сравнивает баллы.

Порог прохождения: средняя ошибка не больше 0.5 band и не меньше 80% работ в пределах ±0.5.
Рекомендуемый объём набора — 30 работ Writing разного уровня (5.0–8.0).

Формат файла `agent/calibration/writing/<имя>.md`:

```markdown
---
task: task2            # task2 | task1-academic | task1-general
band: 6.5              # оценка преподавателя за работу
prompt: "Some people believe that... To what extent do you agree or disagree?"
source: собственная работа / работа ученика с согласия
---

Текст работы целиком...
```

Используйте только работы, на которые у вас есть права (свои или с согласия автора).
Не добавляйте опубликованные «образцовые эссе» из пособий.
